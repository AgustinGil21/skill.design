# Revisión de una landing antes de publicar

Marcar cada punto. Lo que falla en "Mensaje" o "Accesibilidad" bloquea la publicación.

## Mensaje

- [ ] En 5 segundos se entiende qué es, para quién y qué hacer (probado con alguien ajeno).
- [ ] El titular dice un resultado o una idea concreta; no hay palabras huecas.
- [ ] Hay una sola acción principal, repetida al final; la secundaria pesa menos.
- [ ] La objeción principal tiene respuesta visible.
- [ ] Toda cifra, logo y testimonio es real y tiene permiso.

## Estructura

- [ ] Las secciones siguen un arco (problema → cómo → qué → prueba → objeciones → cierre).
- [ ] Ninguna sección sobra (si se saca, nadie la extraña).
- [ ] El ritmo varía: no son bloques iguales apilados.
- [ ] La navegación es corta y la acción principal está siempre a mano.

## Identidad

- [ ] Hay una idea visual que se puede decir en una frase y se repite con variación.
- [ ] Ninguna señal de piloto automático (degradés genéricos, tres tarjetas con ícono, emojis, bancos de imágenes).
- [ ] Las imágenes muestran el producto real o fotografía dirigida.
- [ ] La tipografía tiene jerarquía clara y carácter.

## Movimiento

- [ ] Cada animación tiene un para qué (explicar, dirigir, carácter).
- [ ] La página funciona y se lee entera sin animaciones.
- [ ] Con "reducir movimiento" no hay desplazamientos ni parallax.
- [ ] Todo lo que se mueve solo más de 5 s se puede pausar; nada destella.
- [ ] Solo se anima transform/opacity; no traba en un teléfono de gama media.

## Accesibilidad

- [ ] Un `h1`, `h2` por sección, regiones y enlace para saltar al contenido.
- [ ] Contraste 4,5:1 (texto) y 3:1 (grande y componentes), incluido texto sobre imágenes.
- [ ] Todo funciona con teclado y el foco se ve.
- [ ] Imágenes con texto alternativo útil; video con subtítulos y sin sonido automático.
- [ ] Zoom al 200 % y 320 px de ancho sin romperse.

## Rendimiento y SEO

- [ ] LCP ≤ 2,5 s, CLS ≤ 0,1, INP ≤ 200 ms en móvil.
- [ ] Imagen del hero optimizada y priorizada; resto diferido.
- [ ] Título, descripción, Open Graph e imagen para redes escritos a mano.
- [ ] Texto real en el HTML; datos estructurados donde aplica.

## Móvil

- [ ] El hero entra en la primera pantalla con titular, bajada y botón visibles.
- [ ] Botones de 44 px de alto, separados; nada depende de hover.
- [ ] Tablas y comparaciones se reorganizan (no se achican).
- [ ] Menú accesible y cerrable con un toque y con Esc.

## Después de publicar

- [ ] Métrica principal medida por fuente de tráfico.
- [ ] Revisar grabaciones o mapas de clic a la semana.
- [ ] Una prueba A/B por vez, con hipótesis escrita.
