# Landing pages

Cómo hacer landings que se entienden en cinco segundos, convencen con hechos, tienen una idea visual propia, se
mueven con intención y funcionan para todos. Complementa la base general (`../00-principios.md` en adelante) y
reemplaza en profundidad a [../patrones/paginas-de-producto.md](../patrones/paginas-de-producto.md).

## Orden de trabajo

1. [01-estrategia-y-estructura.md](01-estrategia-y-estructura.md): objetivo, público, la objeción principal y el
   orden de las secciones según el tipo de landing.
2. [04-escritura-persuasiva.md](04-escritura-persuasiva.md): escribir el titular, la bajada y cada sección **antes**
   de diseñar. Si el texto no convence, el diseño no lo salva.
3. [05-direccion-de-arte-y-creatividad.md](05-direccion-de-arte-y-creatividad.md): elegir una idea visual (un
   concepto, no un estilo) y su sistema.
4. [02-hero.md](02-hero.md) y [03-secciones.md](03-secciones.md): resolver cada bloque.
5. [06-animacion.md](06-animacion.md): movimiento con propósito, presupuesto y alternativa reducida.
6. [07-accesibilidad-rendimiento-y-seo.md](07-accesibilidad-rendimiento-y-seo.md): que cargue rápido, se lea con
   cualquier herramienta y se encuentre.
7. [08-revision.md](08-revision.md): lista final antes de publicar.

## Las cinco preguntas que una landing responde

1. ¿Qué es? (en una frase, sin jerga)
2. ¿Para quién? (y quién no)
3. ¿Qué gano? (el resultado, no la función)
4. ¿Por qué creerles? (prueba: producto real, números, personas reales)
5. ¿Qué hago ahora? (una acción, con el riesgo bajo dicho)

Si alguien que no conoce el producto no puede contestar las cinco después de mirar el primer pantallazo y bajar un
poco, la landing todavía no está.
